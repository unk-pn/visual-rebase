# Change Log

All notable changes to the "visual-rebase" extension will be documented in this file.

## [0.0.1] - 2026-04-03

- Initial release of the extension
- Added automatic interception of `git-rebase-todo` files
- Implemented visual webview interface for commits
- Added safe "Cancel Rebase" functionality

## [0.0.2] - 2026-04-12
- Add `Commit` button to commit and not push (if you are working on local repo/branch for example)

## [0.0.3] - 2026-09-19
- Refactor project structure

## [0.0.4] - 2026-10-18
- Add multi-editor support (VSCodium, Cursor, custom IDEs)
- Add auto-detection of the current IDE for integrated terminal
- Add `visualRebase.editor` and `visualRebase.customEditorCommand` configuration settings
